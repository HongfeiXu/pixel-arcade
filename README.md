## 推箱子：小小搬运员

12 个手工小关卡，第一关只需向右推一步。没有计时、星级和惩罚，支持无限撤销、重来、自由选关与本机自动继续（含撤销历史）。手机使用大方向键；电脑方向键/WASD 移动、Z/Backspace 撤销；TV 方向键每按一次走一步，OK/返回打开操作菜单，菜单可撤销、重来、选关或返回大厅。通关后主动进入下一关。

实现说明与验收清单：[推箱子设计](docs/dev/feature-008-sokoban.md)。新增内容尚未发布到在线地址；Sony 真机与浏览器体验仍待验收。
