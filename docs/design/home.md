# 游戏大厅 — 设计文档

## 概述

游戏大厅是应用首页，展示所有可玩的游戏，孩子点击即可进入。

## 布局

竖屏全屏布局：

```
┌──────────────────────────────┐
│  🎮 像素游戏厅               │  ← 标题区（像素风 Logo）
├──────────────────────────────┤
│                              │
│  ┌──────────┐  ┌──────────┐  │
│  │ 游戏封面  │  │ 游戏封面  │  │  ← 游戏卡片网格
│  │   图片    │  │   图片    │  │    2 列布局
│  │          │  │          │  │
│  │ 俄罗斯方块│  │ 敬请期待  │  │
│  │ ⭐ 最高12 │  │   🔒     │  │
│  └──────────┘  └──────────┘  │
│                              │
│  ┌──────────┐  ┌──────────┐  │
│  │          │  │          │  │
│  │ 敬请期待  │  │ 敬请期待  │  │
│  │   🔒     │  │   🔒     │  │
│  └──────────┘  └──────────┘  │
│                              │
├──────────────────────────────┤
│         🔇 音效开关           │  ← 底部设置区
└──────────────────────────────┘
```

TV Mode（`?tv=1` 或符合大屏横屏检测条件）使用 5% overscan 安全区和四列卡片布局。方向键在四列网格内做空间导航，末行不足四项时落到最近卡片；最后一行向下进入音效按钮。焦点包含白色描边、亮色阴影和缩放反馈，并在返回大厅时恢复离开前的卡片。

## 游戏卡片

每个卡片包含：

- 游戏封面图（像素风插画或游戏截图）
- 游戏名称
- 历史最高分（星星数）
- 状态标识：可玩 / 即将推出（锁定图标 + 灰色遮罩）

卡片点击后进入对应游戏页面，使用淡入过渡（200ms opacity，参见 [视觉规范](visual-guide.md#动画)）。

## 交互

- 可玩的游戏卡片点击后直接进入游戏
- 未上线的游戏卡片点击后轻微抖动，不跳转
- 页面支持纵向滚动（游戏多了之后）
- 底部音效开关控制全局 `soundEnabled` 设置（存入 `pixelarcade_settings`），游戏内的静音按钮读取同一设置
- TV 遥控 Select 激活当前焦点；大厅 Back 交给浏览器或宿主处理
- `coming_soon` 卡片仍可聚焦并触发现有抖动反馈，不使用 `disabled` 破坏焦点路径

## 数据

- 历史最高分从 `pixelarcade_scores` 读取，无记录时显示"⭐ —"（短横线占位）
- 游戏列表从 `games/registry.ts` 读取
