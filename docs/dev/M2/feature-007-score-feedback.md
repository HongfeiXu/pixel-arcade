# Feature-007: 得分浮动反馈

## 背景

俄罗斯方块系列采用 1/3/5/8 非线性消行奖励后，仅更新顶栏累计分数不足以突出多行消除的价值。增加短暂的得分浮动反馈，让玩家在不离开棋盘视线的情况下感受到本次奖励强度。

## 本次范围

- 适用于俄罗斯方块（简单）、俄罗斯方块和反重力方块
- 得分后在棋盘区域中央偏上显示 `+N`
- 动效覆盖在 Canvas 上方，不改变布局、不拦截输入
- 只响应真实得分事件；开始、重启、读档和恢复总分时不触发
- 本轮三款游戏统一向上浮动

## 三级反馈

| 级别 | 得分 | 视觉表现 | 时长 |
|------|------|----------|------|
| 轻量 | +1 | 小号浅色，轻微上浮并淡出 | 520ms |
| 强调 | +3 / +5 | 中号黄色、加粗，弹跳后上浮淡出 | 680ms |
| 爆发 | +8 | 大号亮黄色、像素描边和火花，强缩放后上浮淡出 | 900ms |

## 架构

1. `GameInstance` 增加可选的 `onScoreGain(points)` 回调。
2. 方块游戏在消行结算时同时发出本次得分和累计分数。
3. `useGame` 把每次得分包装成带递增 id 的瞬时事件。
4. `GamePage` 在 `canvasArea` 内渲染 React `ScorePopup`。
5. `ScorePopup` 根据得分选择三级样式；更换事件 id 时重新播放动画。

## 后续

- 反重力方块的得分动效改为向下飘，强化重力方向反转的主题。
- 贪吃蛇得分节奏不同，本次不套用该动效，后续单独设计吃食物反馈。
