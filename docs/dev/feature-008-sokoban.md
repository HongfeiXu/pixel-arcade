# 推箱子：原版 12 关设计（历史）

当前扩展以 [feature-009](feature-009-sokoban-expansion.md) 为准：24 关、Microban 署名布局、数字关号/范围、取消可见标题和教学叙事，复用 Arcade UI。下文仅保留原版设计和验收历史。

## 已确认范围

面向 5 岁孩子的经典推箱子：不计时、不设星级、不惩罚。12 个手工小关卡，从一步推到目标开始，逐步学习走路、绕到箱后、转弯、多个箱子与规划顺序。不是随机生成关卡。

## 交互与视觉

- 墙为砖纹、地板为浅色瓷砖、木箱有叉形木条、目标为空心菱形、到位箱子有大勾：不能只靠颜色区分。
- 无限撤销（包括通关后的最后一步）、重来本关、随时选关；所有关卡开放，无解锁压力。
- 过关展示简短庆祝动效，下一关按钮立即可用，不自动跳关，保留撤销机会。
- 竖屏大方向键、常显撤销；桌面方向键/WASD，Z/Backspace 撤销。
- TV 沿用现有 Sony 键值归一化。每次按下只走一步，忽略系统 repeat 和未松开重复事件；松开后才能再次移动，避免误推。OK/返回打开菜单，方向选项、OK 执行撤销/重来/选关/大厅，返回关闭菜单。其他游戏输入不变。

## 架构与存档

纯 TS `SokobanGame` 实现 `GameInstance`，无 React/localStorage 依赖；静态回合制按变化渲染，无需空转 rAF。独立 React 页面通过 `useGame` 管理生命周期、可见性和存档；统一接口增加可选 puzzle 能力，旧游戏不需修改。专用路由优先于通用游戏页。大厅新增像素图标，显示轻松练习而非星星。

存档沿用 `pixelarcade_sokoban_state`，版本化保存当前关卡、已完成关卡和完整操作历史；历史无条数限制，以初始布局重放验证，拒绝错误版本/越界/非法历史。每次有效操作、选关即存，暂停/离开照常保存。重来仅清本关棋盘，不清完成记录。存储不可用时仍可游玩。
