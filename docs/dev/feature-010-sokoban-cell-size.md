# 推箱子固定格子尺寸

## 用户要求

人物和格子不随地图大小为了填满屏幕而缩放；保持 Arcade 界面不变。

## 实现约定

- 标准格子边长 48 CSS px，为上限，不因可用空间更大而放大。
- 同一可用游戏区域下，所有关卡共用尺寸。按整套关卡的最大宽高预算空间，而非当前关卡的宽高；空间不足时统一缩小到整数像素。
- Canvas 仍按当前关卡实际格数计算尺寸并由共享布局居中，小关留白；不拉伸 Canvas，也不改变人物相对格子的比例。
- 设备像素比仅提高绘制分辨率，不改变 CSS 尺寸。地图、规则、输入、存档不变。

## 验证

- 单元测试验证全关卡格子相同、宽屏不超过上限、窄屏全关卡放得下、DPR 不改变显示尺寸。
- 浏览器验证手机和电视切关尺寸稳定、无横溢出及人物画面。
- 发布另行确认；本地完成不代表线上更新。
